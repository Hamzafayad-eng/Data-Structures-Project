# CS212 Requirements Checklist

| Requirement | Evidence in this project |
|---|---|
| R1 Manual C++ implementation | `Stack`, `Queue`, `LinkedList`, and `BST` folders contain manual array/node implementations. |
| R2 Stack | `ActionStack` provides `push`, `pop`, `peek`, `isEmpty`, and `size`. It records completed repairs and supports Undo. |
| R3 Queue | `RepairQueue` provides `enqueue`, `dequeue`, `front`, `isEmpty`, and `size`. It manages waiting repair requests. |
| R4 Linked List | `StreetlightList` provides insertion, deletion, search, and traversal for streetlight records. |
| R5 BST | `PoleBST` provides insert, delete, search, inorder, preorder, and duplicate-key handling for Pole ID. |
| R6 Searching or sorting | `StreetlightSorter` manually implements Insertion Sort by priority. |
| R7 Usable menu | `StreetlightRepairDesk` has a repeatable menu, formatted messages, CRUD operations, and Exit. |
| R8 Validation | `InputHelper` handles non-numeric input. The program handles duplicate IDs, missing IDs, empty structures, root-only BST, and full fixed arrays. |
| R9 Integrated behavior | Add, report, process, undo, update, and delete operations synchronize the linked list, BST, Queue, and Stack. |
| R10 Testing and analysis | `Tests/Manual_Test_Plan.md` and `Documentation/Design_Decisions.md` provide test cases, edge cases, complexity, and limitations. |
