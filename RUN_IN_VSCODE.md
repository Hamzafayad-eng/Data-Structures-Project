# Run the Project in VS Code

1. Double-click `StreetlightRepairDesk.code-workspace`.
2. In VS Code, press `F5`.
3. If VS Code asks which debugger to use, choose `C/C++ Runner: Debug Session`.
4. A console window opens with the numbered project menu. Use the menu normally.

The F5 configuration compiles all `.cpp` files in `Source_Code` together. It is necessary because this is a multi-file project, not a single C++ file.

If VS Code shows a compiler error before the menu appears, copy the complete error text and send it here. Do not change the C++ source files before checking the error.
